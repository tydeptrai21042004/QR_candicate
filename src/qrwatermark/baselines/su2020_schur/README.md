# Su et al. (2020) Schur baseline

Reference: Q. Su, X. Zhang, G. Wang, *An improved watermarking algorithm for color image using Schur decomposition*, Soft Computing 24 (2020), 445–460, DOI 10.1007/s00500-019-03924-5.

The accessible publication description states that two temporary watermarked blocks are generated: one by embedding into the upper-triangular Schur matrix and one by embedding into the unitary matrix; the lower-distortion block is retained and its branch flag is stored for semi-blind extraction. The authors' original source and all equation-level details were not included in the uploaded repository. This module is a transparent reconstruction of that published two-candidate structure for the unified binary benchmark and is not the authors' official implementation.
